# Сохранение слов в Vibeling

Слова сохраняются инструментами MCP-сервера `vibeling`.

## 1. Проверка

Вызови `get_profile`.
- Инструмента нет или ответ «Unauthorized» — попроси ученика набрать `/mcp`,
  выбрать `vibeling` и авторизоваться, затем повтори. Слова до тех пор не теряй:
  покажи их списком.
- `pro: false` — скажи, что сохранение требует Vibeling PRO (покупается в
  приложении), и остановись.

## 2. Подготовка списка

Каждую запись сведи к словарной форме: инфинитив, единственное число, без
артиклей и пометок. «a teacher — учитель» → `teacher`, «he is» → `be`.
Устойчивые выражения («there is», «how are you») попробуй добавить целиком;
если Vibeling их не находит — добавь главное слово и скажи ученику.
Повторы в списке убери.

## 3. Добавление

Для каждого слова — `add_word { word, fromLanguage, toLanguage }`, где языки из
`profile.md` (изучаемый и родной). Пачек нет: по одному вызову на слово.

- Слово добавлено — запомни его `meaningId`.
- Несколько значений (`CHOOSE_MEANING`) — выбери то, чей перевод совпадает со
  смыслом из урока, и вызови снова с этим `meaningId`. Не ясно — спроси ученика.
- `PENDING` — карточка собирается; продолжи с другими словами и вернись к этому
  в конце.
- Ошибка — запиши причину и иди дальше.

## 4. Тег урока

Вызови `list_tags`; тега с именем «Урок N. Название» (если слова из урока) нет —
`create_tag`. Затем `tag_word { meaningIds, tagIds }` для всех добавленных слов.
Слова не из урока — без тега, если ученик не попросил.

## 5. Отчёт

Коротко: сколько добавлено, какие не удалось и почему. Слова появятся в
приложении после синхронизации. Допиши в раздел урока в `progress.md` строку
`- В Vibeling: N слов, тег «…»`.

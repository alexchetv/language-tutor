# Сохранение слов в Anki

Слова сохраняются через локальный HTTP API AnkiConnect. Anki Desktop должен быть
открыт.

## 1. Проверка

1. Прочитай `profile.md`: изучаемый язык, родной язык, `AnkiConnect URL`,
   `Колода Anki`, `Тип заметки Anki`.
2. Отправь POST на `AnkiConnect URL`:

   ```json
   {"action":"version","version":6}
   ```

3. Нет ответа или соединение отклонено — попроси ученика открыть Anki. Если
   AnkiConnect не установлен, попроси установить дополнение с кодом `2055492159`
   и перезапустить Anki. Слова не теряй: покажи их списком.
4. Вызови `deckNames`. Если колоды из профиля нет — создай её:

   ```json
   {
     "action": "createDeck",
     "version": 6,
     "params": {
       "deck": "Language Tutor::English"
     }
   }
   ```

5. Вызови `modelNames`. Если типа заметки из профиля нет — остановись и попроси
   ученика выбрать существующий тип заметки или вернуть `Basic`.
6. Вызови `modelFieldNames` для типа заметки. Для стандартной настройки нужны
   поля `Front` и `Back`.

## 2. Подготовка списка

Каждую запись сведи к словарной форме: инфинитив, единственное число, без
артиклей и пометок. «a teacher — учитель» → `teacher`, «he is» → `be`.

Для каждой карточки подготовь:

- `front`: слово или устойчивая фраза на изучаемом языке.
- `back`: перевод на родной язык, один пример из урока и название урока.
- `tags`: `language_tutor`, код изучаемого языка, уровень, `lesson_N`.

Повторы в списке убери. Если ученик дал перевод или пример, сохрани их. Если
перевода нет, добавь краткий перевод сам на языке объяснений.

## 3. Добавление

Для стандартного `Basic` подготовь массив `notes`:

```json
{
  "action": "canAddNotes",
  "version": 6,
  "params": {
    "notes": [
      {
        "deckName": "Language Tutor::English",
        "modelName": "Basic",
        "fields": {
          "Front": "teacher",
          "Back": "учитель<br><br><b>Example</b>: I am a teacher.<br><b>Lesson</b>: Урок 1. I am, you are, he is"
        },
        "options": {
          "allowDuplicate": false,
          "duplicateScope": "deck"
        },
        "tags": [
          "language_tutor",
          "en",
          "A1",
          "lesson_1"
        ]
      }
    ]
  }
}
```

Затем:

1. Вызови `canAddNotes` с подготовленным массивом `notes`.
2. В результатах `canAddNotes` оставь только карточки, которые можно добавить.
   Если ответ пришёл старым форматом `true` / `false`, считай `false` дублем или
   ошибкой полей. Если ответ содержит объект с `canAdd` и `error`, используй
   `error` в отчёте.
3. Добавляемые карточки отправь через `addNotes` с тем же массивом `notes`:

   ```json
   {
     "action": "addNotes",
     "version": 6,
     "params": {
       "notes": []
     }
   }
   ```

4. `addNotes` возвращает идентификаторы созданных заметок. Если он вернул ошибку
   на всю пачку, попробуй добавить карточки по одной через `addNote`, чтобы
   сохранить те, которые не конфликтуют.

Правила:

- Экранируй HTML-символы в словах, переводах и примерах.
- Для нескольких слов сначала используй один `canAddNotes`, затем один
  `addNotes` для прошедших проверку карточек.
- Если тип заметки не `Basic`, используй поля, которые вернул `modelFieldNames`,
  и спроси ученика, какое поле должно быть лицом и оборотом карточки, если это
  не очевидно.

## 4. Отчёт и прогресс

Коротко сообщи:

- сколько карточек добавлено;
- сколько уже было в колоде;
- какие не удалось добавить и почему;
- в какую колоду они попали.

Допиши в раздел урока в `progress.md` строку:

```text
- В Anki: N карточек, колода «Language Tutor::English», теги language_tutor en A1 lesson_N
```

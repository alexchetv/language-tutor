# Настройка профиля

1. Прочитай `profile.md` и покажи текущие настройки одним списком.
2. Спроси, что поменять. Если ученик уже сказал («хочу учить немецкий с нуля») —
   не переспрашивай, выведи значения сам: язык `de`, уровень `A1`.
   Уровень не знает — предложи A1 для «с нуля», A2 для «знаю основы», B1 для
   «объясняюсь, но с ошибками».
3. Запиши изменения в `profile.md`, сохранив формат файла. При смене языка
   предложи обновить колоду Anki, например `Language Tutor::German` для немецкого.
4. Проверь AnkiConnect:
   - Возьми `AnkiConnect URL` из `profile.md`, по умолчанию
     `http://127.0.0.1:8765`.
   - Отправь POST:

     ```json
     {"action":"version","version":6}
     ```

   - Если нет ответа или соединение отклонено — скажи ученику установить Anki
     Desktop, установить дополнение AnkiConnect с кодом `2055492159`,
     перезапустить Anki и оставить Anki открытым.
   - Если ответ есть — вызови `deckNames`. Если колоды из `profile.md` нет,
     предложи создать её через `createDeck`.
   - Вызови `modelNames`. Если типа заметки из `profile.md` нет, предложи
     использовать `Basic` или указать существующий тип заметки.
   - Для выбранного типа заметки вызови `modelFieldNames` и проверь, что есть
     поля `Front` и `Back`. Если поля другие, попроси ученика указать подходящий
     тип заметки или обнови инструкцию `/save-words` под эти поля.
5. Нет `lessons/<язык>/plan.md` для выбранного языка — предложи `/plan-lessons`.
   Есть — предложи `/lesson`.

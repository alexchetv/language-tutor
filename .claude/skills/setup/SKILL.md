# Настройка профиля

1. Прочитай `profile.md` и покажи текущие настройки одним списком.
2. Спроси, что поменять. Если ученик уже сказал («хочу учить немецкий с нуля») —
   не переспрашивай, выведи значения сам: язык `de`, уровень `A1`.
   Уровень не знает — предложи A1 для «с нуля», A2 для «знаю основы», B1 для
   «объясняюсь, но с ошибками».
3. Запиши изменения в `profile.md`, сохранив формат файла.
4. Проверь Vibeling: вызови `get_profile` у MCP-сервера `vibeling`.
   - Инструмента нет или ответ «Unauthorized» — скажи ученику набрать `/mcp`,
     выбрать `vibeling` и пройти авторизацию (код привязки берётся в приложении:
     Профиль → Настройки → Мои устройства → «Подключить новое устройство»;
     приложения нет — на той же странице есть «Создать новый аккаунт»).
   - `pro: false` — предупреди, что сохранение слов требует Vibeling PRO, а уроки
     работают и без него.
   - Изучаемый язык в Vibeling не совпадает с `profile.md` — это не ошибка:
     `/save-words` передаёт языки явно. Просто упомяни.
5. Нет `lessons/<язык>/plan.md` для выбранного языка — предложи `/plan-lessons`.
   Есть — предложи `/lesson`.

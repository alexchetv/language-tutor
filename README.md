# Anki Language Tutor

Репетитор иностранного языка внутри [Claude Code](https://claude.com/claude-code).
Claude составляет план уроков, проводит их в чате — объяснение, примеры, задания
с проверкой — и сохраняет выученные слова в Anki через
[AnkiConnect](https://ankiweb.net/shared/info/2055492159).

Готовый пример — английский с нуля (`lessons/en/plan.md`), но язык, уровень и
язык объяснений настраиваются.

## Установка

Нужны Claude Code, Anki Desktop и дополнение AnkiConnect.

```bash
git clone <url-вашего-репозитория>
cd language-tutor
claude
```

## Подключение Anki

1. Установите Anki Desktop: https://apps.ankiweb.net
2. В Anki откройте Tools → Add-ons → Get Add-ons.
3. Вставьте код AnkiConnect: `2055492159`.
4. Перезапустите Anki.
5. Оставьте Anki открытым во время сохранения слов.

AnkiConnect принимает локальные HTTP-запросы по адресу
`http://127.0.0.1:8765`. Интернет для сохранения карточек не нужен.

По умолчанию проект сохраняет карточки в колоду `Language Tutor::English` и
использует стандартный тип заметки `Basic`:

| поле | содержимое |
|---|---|
| `Front` | слово или фраза на изучаемом языке |
| `Back` | перевод, пример и название урока |

Колоду и тип заметки можно поменять в `profile.md`.

## Как заниматься

| команда | что делает |
|---|---|
| `/setup` | выбрать язык, уровень, язык объяснений, цель; проверить AnkiConnect |
| `/plan-lessons` | составить план уроков под ваш язык и уровень |
| `/lesson` | пройти следующий урок; `/lesson 7` — конкретный |
| `/save-words` | сохранить слова в Anki |

Можно и словами: «давай заниматься», «хочу учить испанский с нуля», «повтори
урок 3».

Настройки лежат в `profile.md`, план — в `lessons/<язык>/plan.md`, ваш прогресс —
в `progress.md` (в git не попадает).

## Другой язык

```text
/setup
> хочу учить испанский, уровень A2, объясняй по-русски
/plan-lessons
/lesson
```

После смены языка проверьте в `profile.md` название колоды Anki. Например, для
испанского удобно использовать `Language Tutor::Spanish`.

## Устройство

```text
CLAUDE.md                 роль репетитора и правила урока
profile.md                ваши настройки, включая Anki
lessons/<язык>/plan.md    план уроков
.claude/skills/           setup, plan-lessons, lesson, save-words
.mcp.json                 пустая MCP-конфигурация; AnkiConnect не требует MCP
```
